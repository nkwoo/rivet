# 파일 전송

SFTP, FTP, FTPS 연결은 왼쪽에 로컬, 오른쪽에 원격 파일을 놓은 2단 탐색기로 엽니다.
SSH 연결은 탭의 **화면** 전환에서 **파일**을 고르면 같은 연결로 SFTP를 씁니다.

![SFTP 파일 탐색기](/screenshot2.png)

## 올리기와 내려받기

- 파일을 골라 **업로드** / **다운로드** 버튼을 누르거나, 반대쪽 창으로 끌어 놓습니다.
- Finder나 탐색기에서 원격 창으로 끌어 놓아도 업로드됩니다.
- 여러 파일과 폴더를 한 번에 고를 수 있습니다.
- 경로 막대에 경로를 바로 입력할 수 있고, <kbd>Backspace</kbd>로 상위 폴더로 갑니다.

원격 창에서는 새 폴더, 이름 바꾸기, 삭제를 할 수 있습니다. 폴더는 비어 있을 때만 삭제됩니다.

## 전송 큐

전송은 아래 큐에 쌓여 한 번에 3개씩 진행됩니다. 진행률을 보여 주며, 실패한 항목은 **다시 시도**할 수 있습니다.

같은 이름의 파일이 있을 때의 동작은 큐 위의 **같은 이름이 있으면**에서 고릅니다.

| 선택 | 동작 |
|---|---|
| 매번 묻기 | 있는 파일의 크기·수정 날짜와 보낼 파일의 크기를 보여 주고 덮어쓰기/건너뛰기를 묻습니다. 남은 항목에 같은 선택을 적용할 수 있습니다 |
| 더 최신이면 덮어쓰기 | 보낼 파일이 더 최근에 수정됐을 때만 덮어씁니다 |
| 덮어쓰기 | 항상 덮어씁니다 |
| 건너뛰기 | 항상 건너뜁니다 |

내려받는 파일은 `.rivetpart`로 쓴 뒤 다 받으면 원래 이름으로 바꿉니다. 중간에 실패해도 기존 파일이 망가지지 않습니다.

## 안전장치

- 원격에서 받은 파일 이름이 `../`나 절대 경로처럼 대상 폴더 밖을 가리키거나, Windows에서 쓸 수 없는 이름(`CON`, `aux.txt` 등)이면 내려받지 않습니다.
- 심볼릭 링크는 따라가지 않고 건너뜁니다.
- 한 폴더의 항목이 너무 많으면(20,000개) 일부만 보여 줍니다.

## FTP와 FTPS

- 기본은 패시브 모드입니다.
- 포트 990은 암시적 TLS, 그 밖의 포트(보통 21)는 `AUTH TLS`로 접속합니다.
- 운영체제가 신뢰하지 않는 인증서(자체 서명 등)는 SHA-256 지문을 확인한 뒤 고정합니다. 고정한 인증서가 바뀌면 연결을 차단합니다.
- **평문 FTP**는 비밀번호와 파일 내용을 암호화하지 않습니다. 연결 화면과 상태 표시줄에 경고가 계속 표시됩니다.

::: tip Windows 서버에 파일 전송
Windows 서버는 기본 탑재된 OpenSSH 서버를 켜고 SFTP로 접속하는 방법을 권장합니다.
:::

목록은 되는데 전송이 안 되면 [문제 해결](./troubleshooting#ftp-목록이나-전송이-안-됨)을 참고하세요.
