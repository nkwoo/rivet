# 연결 만들기

## 새 연결

오른쪽 위의 **새 연결**을 누르고 프로토콜을 고릅니다.

| 프로토콜 | 기본 포트 | 용도 |
|---|---|---|
| SSH | 22 | 터미널. 같은 연결로 파일 전송(SFTP)도 함께 씁니다 |
| SFTP | 22 | 터미널 없이 파일 전송만 |
| FTPS | 990 (암시적 TLS). 그 밖의 포트(보통 21)는 AUTH TLS | TLS로 암호화한 FTP |
| FTP | 21 | 암호화하지 않은 FTP. 가능하면 쓰지 마세요 |
| RDP | 3389 | Windows 원격 데스크톱 |

이름, 호스트, 포트, 사용자명을 넣고 인증 방식을 고릅니다. 그룹, 태그, 즐겨찾기, 메모로 목록을 정리할 수 있습니다.

### SSH 인증 방식

- **개인 키**: 키 파일 경로를 지정합니다. 패스프레이즈가 있으면 연결할 때 묻습니다.
- **비밀번호**: 연결할 때 묻습니다.
- **ssh-agent**: 실행 중인 에이전트의 키를 씁니다. macOS는 `SSH_AUTH_SOCK`, Windows는 OpenSSH 인증 에이전트 서비스(`ssh-agent`)를 씁니다.

### 비밀번호 저장

비밀번호나 패스프레이즈를 묻는 창에서 **시스템 키체인에 저장**을 고르면 인증에 성공한 경우에만 저장합니다.
macOS 키체인 또는 Windows 자격 증명 관리자에만 보관하며, Rivet 자체 파일에는 기록하지 않습니다.
저장한 값은 연결 편집 화면의 **저장된 비밀 값 삭제**로 지울 수 있습니다.

## 연결하기

왼쪽 목록에서 연결을 누릅니다. <kbd>⌘K</kbd> (Windows <kbd>Ctrl+K</kbd>)로 검색창에 바로 갈 수 있습니다.

처음 접속하는 SSH 서버라면 호스트 키 지문을 보여 줍니다. 서버 관리자에게 받은 지문이나 서버에서 확인한 값과 같을 때만
**신뢰하고 연결**을 누르세요. 자세한 내용은 [보안](./security)을 참고하세요.

## ~/.ssh/config 가져오기

사이드바의 **~/.ssh/config 가져오기**로 OpenSSH 설정의 호스트를 한 번에 가져옵니다.

- `Host`, `HostName`, `Port`, `User`, `IdentityFile`, `ProxyJump`, `Include`, 와일드카드 기본값(`Host *`)을 읽습니다.
  `Match` 블록은 조건을 평가할 수 없어 건너뜁니다.
- 키 파일이 있으면 개인 키, 없으면 ssh-agent 인증으로 만듭니다.
- `ProxyJump`는 같은 이름의 연결을 점프 호스트로 설정합니다.
- 비밀번호와 패스프레이즈는 가져오지 않습니다.
- 같은 호스트·포트·사용자의 연결이 이미 있으면 기본으로 선택하지 않습니다.

## 점프 호스트

연결 편집 화면의 **점프 호스트**에서 다른 SSH 연결을 고르면, 그 서버를 거쳐 접속합니다(OpenSSH의 `ProxyJump`).

- 점프 호스트에도 점프 호스트를 지정할 수 있으며 최대 4단계까지 이어집니다.
- 단계마다 호스트 키를 따로 검증합니다.
- 점프 호스트를 삭제하면 그 서버를 거치던 연결은 직접 연결로 바뀝니다.
- RDP 연결도 점프 호스트를 지정해 SSH 터널을 거쳐 접속할 수 있습니다. [원격 데스크톱](./rdp#ssh-터널을-거쳐-접속) 참고.

## 여러 개 삭제

목록에서 **선택해서 삭제**를 누르고 여러 연결을 고른 뒤 삭제합니다. 키체인에 저장한 비밀번호도 함께 지우며,
열려 있는 세션은 연결을 끊고 탭을 닫습니다.
