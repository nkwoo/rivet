# 업데이트

## 새 버전 확인

- Rivet은 시작하고 5초 뒤 GitHub Releases에서 새 버전을 확인합니다. 새 버전이 있으면 상단 막대에 **<버전> 업데이트** 버튼이 나타납니다.
- 직접 확인하려면 상태 표시줄의 버전을 누르거나, macOS 메뉴 **Rivet → 업데이트 확인…**을 고릅니다.
- 시작할 때 확인하지 않으려면 업데이트 대화상자에서 **시작할 때 확인**을 끕니다.

확인할 때는 GitHub에서 버전 정보 파일(`latest.json`)만 받으며, 연결 목록 같은 정보는 보내지 않습니다.

## 설치

버튼을 누르면 새 버전과 변경 내용을 보여 줍니다. **설치 후 다시 시작**을 누르면 내려받아 설치한 뒤 앱이 다시 시작됩니다.

- 열린 탭의 연결은 모두 끊어집니다. 대화상자에 몇 개가 끊기는지 표시합니다.
- 알림만 하고 사용자가 누르기 전에는 설치하지 않습니다.
- Windows는 설치 진행 창이 잠시 나타납니다.

## 서명 확인

업데이트 파일은 Rivet 릴리스 키로 서명되어 있고, 앱에 들어 있는 공개 키로 확인한 뒤에만 설치합니다.
서명에 든 버전이 알림의 버전과 다르면 설치하지 않아, 예전 버전을 새 버전으로 속여 설치하게 할 수 없습니다.

## 직접 설치

[설치](./install) 방법대로 새 버전을 내려받아 덮어 설치해도 됩니다. 연결 목록과 저장한 비밀번호는 그대로 남습니다.

::: info macOS 키체인 확인 창
Rivet은 아직 Apple 개발자 인증서로 서명하지 않아서, 업데이트한 뒤 처음으로 저장된 비밀번호를 쓸 때
macOS가 키체인 접근을 다시 물을 수 있습니다. **항상 허용**을 누르면 됩니다.
:::
